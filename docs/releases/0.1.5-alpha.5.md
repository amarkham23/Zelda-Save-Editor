# Zelda Save Editor 0.1.5-alpha.5

Public prerelease by StockiestThree9. This update retains BOTW support and adds the TOTK development work completed since 0.1.4-beta.1.

## Changes since the store beta

- Experimental Tears of the Kingdom save discovery and editing, with player values, stamina wheels, battery cells, abilities and pouch capacity.
- Grouped item selection: choose an armor family, then its stars and supported style. Hylian Hood up/down is independent of rank. Weapons offer verified Decayed/Pristine and appearance choices. Search and category filters shorten the lists.
- Inventory add/replace/remove/equip, fusion choices, durability repair, armor upgrades, pristine conversion, meal effects and bulk stack tools.
- Registered horses, world/completion flags, compendium states, direct quest stages, map stamps and daily amiibo reset.
- Autobuild slot/favorite management and import/export using this editor's checksummed `.zsbp` format.
- BOTW inventory validation improvements, stale-selection protection after undo/redo, faster change tracking and clearer menu flows.

Game names, item relationships and other resource tables are read from the user's installed game and cached privately. No Nintendo resource cache, save, font or audio sample is distributed.

## Install or update

Extract `Zelda-Save-Editor-v0.1.5-alpha.5.zip` at the SD root, preserving existing files. The executable remains `/switch/Zelda_Save_Editor.nro`; documentation and notices are under `/switch/zelda-save-editor/`. Existing saves, backups, cache, settings and blueprints are not included or replaced by the package. A standalone NRO and a source archive including libpulsar are also provided.

Launch Sphaira in full application mode by holding R while opening the relevant game, then launch Zelda Save Editor. Close the actual game before editing its save. Settings → Game resources can retry loading the installed resources.

## Testing and current limits

Rechecked on 19 October 2026: native Switch build; 495 synthetic/core checks; 580 BOTW real-fixture checks; 7,090 TOTK checks with a real fixture and installed 1.4.3 resources; storage/backup/conflict checks; 230 BOTW normal-profile-swap checks; and both host UI walkthroughs.

This is still an **alpha for TOTK**. Host checks do not establish that every edited save is valid in-game. Gameplay acceptance of the expanded edits and resource loading on a fresh console installation remain unverified. Only one accepted TOTK save revision has a real test fixture. Keep an independent backup and begin with a small edit before testing broader changes.

World/quest edits change saved fields without reconciling all related story events or rewards. Graphical maps, sparse object completion such as individual bosses/Addison signs, full horse creation/customization and community Autobuild formats are not implemented. BOTW profile swapping excludes Master Mode; gameplay after swaps still needs wider device testing.
