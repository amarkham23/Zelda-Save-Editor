# Zelda Save Editor — v0.1.4 beta 1

First public beta by **StockiestThree9**, released under **MIT**. Supports **Breath of the Wild on the original Nintendo Switch family**, including OLED.

## Install

Download **Zelda-Save-Editor-v0.1.4-beta.1.zip** and extract its `switch` folder to your SD root. Launch **Zelda Save Editor** from Sphaira in application mode. Holding R while opening BOTW provides access to the game's resources on first use. Close BOTW before editing.

For an existing installation, the standalone **Zelda_Save_Editor.nro** can replace `/switch/Zelda_Save_Editor.nro`. The ZIP also includes documentation and dependency notices; it contains no settings, cache or backups to overwrite.

## Included

- Native-style interface, compact game picker, Quill & Scroll icon, touch/controller navigation and console-sourced navigation sounds.
- Automatic user selection when only one console user exists.
- Normal, transferred Switch 2 Profile 2, and Master Mode save tabs.
- Light, dark, automatic and OLED black appearance, available before opening a save.
- Hearts, stamina wheels, inventory quantities and labeled whole-number durability; equipment, horses, world fields and advanced editing.
- Undo/redo, explicit write confirmation, verified backups and stale-save checks.
- Normal Profile 1 / Profile 2 swapping with full backups and interruption recovery. Master Mode saves and history are excluded.

## Beta limits

Keep an independent backup before editing. Browsing, interface and audio have been exercised on an OLED Switch, and host checks cover the save reader, writes, backups, recovery and normal-only swaps. **Live save-and-reload and gameplay after a profile swap still need broader console validation.** The real-save fixture is BOTW 1.9.0; other versions are not comprehensively tested.

Shared albums and compendium pictures remain in place during normal-save swaps to preserve Master Mode data, so a swapped normal adventure may show that location's existing pictures. Save thumbnails and normal Hero's Path move with their normal save set. All original files are retained in the verified full backup.

World editing currently exposes fields; illustrated maps and coordinated completion actions are not included. Transferred Profile 2 editing does not make this a native Switch 2 app. An unfinished whole-profile swap from the private 0.1.3 preview must be recovered with that version first.

No Nintendo game files, system fonts, navigation audio, private saves or extracted resources are distributed. These resources are read locally from the console when needed.
